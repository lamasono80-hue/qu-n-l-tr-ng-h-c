# UniConnect Frontend Single Page Application (SPA)

Modern Single Page Application built with React 18, TypeScript, Vite, and TailwindCSS implementing the 24 screens defined in **Phase 3 UI/UX Specification**.

## Screen Directory Layout (`src/pages/`)
- `auth/`: Landing (`SCR-01`), Register (`SCR-02`), Verify (`SCR-03`), Login (`SCR-04`), Forgot Password (`SCR-05`)
- `profile/`: Profile View (`SCR-06`), Edit Profile (`SCR-07`)
- `project-match/`: Feed (`SCR-08`), Detail (`SCR-09`), Create (`SCR-10`), Applications (`SCR-11`)
- `study-buddy/`: Feed (`SCR-12`), Detail (`SCR-13`), Create (`SCR-14`), Connections (`SCR-15`)
- `skill-exchange/`: Feed (`SCR-16`), Detail (`SCR-17`), Create (`SCR-18`), Proposals (`SCR-19`)
- `chat/`: Direct Messaging (`SCR-20`)
- `notifications/`: Alerts Center (`SCR-21`)
- `admin/`: Dashboard (`SCR-22`), Users (`SCR-23`), Moderation (`SCR-24`)
